# 类人问卷孪生 Prompting

面向 LLM 人物卡 / 数字孪生在问卷与定价题（如 Twin-2K-500 的买/不买）上的**纯 Prompt** 方案。目标是对齐**人类方差结构**，而不只追总体准确率。不需要微调。

## 适用场景

- 不同人物卡上，模型答案近乎一致（约 100% 同意），人类则分歧较大（约 50%）。
- 模型题间购买率在 0%↔100% 两极跳；人类题间购买率较扁（约 40–45%）。
- 只能改 prompt、温度与外层抽样，不能改模型权重。

## 先诊断（改写前确认）

典型失败不是「人口学不够」，而是**共用确定性规则**：

1. **温度 0 + 二元题** → 同一套启发式在每张卡上复读。
2. **人物卡缺购买相关信息** → 模型补共享默认（没写宠物 → 一律不买猫粮）。
3. **全局价格锚** → 便宜日用品全买 / 贵零食全不买。
4. **目标错位** → 模型讲自洽的「理性消费者」故事；人类在调查里随手勾（噪声、懒、冲动）。

若收入、宗教、婚姻等几乎不动结果，**不要**先堆更多人口学。优先改抽样、题面 framing 与人级噪声。

## 原则

1. 不要让模型判断「该不该买」，要让它「以这个人的身份随手勾调查」。
2. 优先 **输出概率 → 外层 Bernoulli 抽样**，避免温度 0 硬判买/不买。
3. 给每个孪生一张**整场共用的稳定口味/倾向卡**。
4. 禁止长串「价格公不公平」推理；限制直觉长度。
5. 评估与优化以**方差结构**为主，准确率为辅。

## 步骤 1 — 系统角色（替换理性消费者）

```text
你在填写一份市场调查，不是在做消费决策咨询。
你就是下面描述的这个人。回答要快，可以不一致，可以凭感觉。
不要写长推理，不要判断「这价公不公平」。
不要补全卡上没写的「应该有的需求」。
卡上没写的偏好，用你抽到的个人倾向决定，不要用所有人都一样的默认规则。
```

## 步骤 2 — 人级潜变量卡（整场调查固定）

在进入逐题循环前，为该孪生附上一组倾向（用 person id 做种子，或在外部随机后粘贴进 prompt）：

```text
【本轮个人倾向｜整场调查固定不变】
- 问卷认真度：低 / 中 / 高（低 = 经常随便点）
- 价格敏感：低 / 中 / 高
- 冲动：低 / 中 / 高
- 对新奇零食 / 电子小件：排斥 / 无所谓 / 想试试
- 对「看起来贵的日用品」：死抠 / 一般 / 不在乎
- 未知品类默认：偏向不买 / 五五开 / 偏向买
用这些倾向回答所有题；不要每题重新发明一套价值观。
```

**关键：** 不同人必须抽到**不同**组合；同一人在全部题目（如 40 题）上共用**同一张**倾向卡。

## 步骤 3 — 单题模板（推荐：输出 p，外层抽样）

```text
商品：{product}
标价：{price}

只根据人物卡 + 上面的个人倾向，估计「你会点购买」的概率。
要求：
1) 先用一句话直觉（≤15 字），禁止「价格是否离谱」的长分析
2) 再给出 buy_prob，必须在 0.15–0.85 之间（调查里很少有绝对确定）
3) 不要输出最终买/不买

只输出 JSON：{"gut":"...","buy_prob":0.xx}
```

外层代码：`decision = random() < buy_prob`。

若无法外层抽样：温度设为 **0.7–1.0**，直接输出 `buy` / `skip`，但仍保留倾向卡、短直觉禁令与「调查勾选」framing。

## 步骤 4 — 硬性禁止（打掉常见坍缩启发式）

```text
禁止：
- 「没写养宠物 → 不买宠物用品」→ 未知时按个人倾向与约五五开决定
- 「贵 → 全不买 / 便宜 → 全买」→ 价格最多轻微移动概率，不得压到 0/1
- 把外部「合理市场价」当作唯一依据
- 信息不足时，buy_prob 靠近 0.4–0.6，不要极端
```

## 步骤 5 — 可选 few-shot（人类风格，非理性风格）

```text
例：贵一点的电池 → gut:「懒得比价」→ buy_prob: 0.48
例：便宜纸巾 → gut:「随便」→ buy_prob: 0.55
```

**不要**放「深度分析后坚定不买/必买」的示例。

## 步骤 6 — 消融顺序（只改 prompt）

| 条件 | 改什么 | 看什么 |
|------|--------|--------|
| 基线 | 当前 prompt + 温度 0 | 人与人一致性 ≈100% |
| P1 | +个人倾向卡 + 禁长推理 + 温度 0.8 直接买/不买 | 跨人分歧是否上升 |
| P2 | P1 + 输出 buy_prob + 外层 Bernoulli | 题间是否不再 0%/100% 两极 |
| P3 | P2 + 禁止贵便宜绝对化 + 概率夹在 0.15–0.85 | 40 题购买率是否挤回约 40–45% |

## 评估指标（优先于单纯准确率）

- 同一题上**跨人购买率标准差** ↑（向人类靠拢）。
- **题间**平均购买率极差 ↓（人类往往较扁）。
- 与人类 **test–retest**（如 wave3 vs wave4）比稳定性：孪生不应比人重复自己更稳。
- 总需求曲线次要；「更像人」首先看方差结构。

## 反模式

- 人口学已几乎不动结果时，继续堆标签。
- 温度 0 +「一步步思考这笔消费是否合理」。
- 缺字段时全员共用同一默认。
- 只优化题级准确率，却人人答成一样。

## 运行本技能时应交付

给出：(1) 可直接粘贴的系统角色 + 倾向卡 + 单题 prompt；(2) 抽样规则；(3) 针对用户当前 prompt 的最小消融表。若用户贴出原文，应**原地改写完整稿**，不要只列零件。
