gpt-5.5、glm-5.3、deepseek-v4-pro 用同一批 50 张 ATUS 人物卡回答了 14 道人口学闭卷题。平均总变异距离把 gpt-5.5 放在第一（0.243），平均选项份额均方误差把 deepseek-v4-pro 放在第一（0.0136）。性别、年龄、学历三题三个模型的答案完全相同；两种指标的名次差，来自宗教活动、党派和政治倾向上误差怎么汇总。

TVD = ½ Σ |pi − qi|　　MSE = (1/n) Σ (pi − qi)2
pi 是模拟人群选第 i 个选项的比例，qi 是 Twin-2K 的对应比例，n 是该题选项数。TVD 是至少要改选的人数比例。MSE 是各选项比例差的平方平均。

这 50 人是怎么抽出来的

四个教育水平按 ATUS 终权 TUFINLWGT 之和分配 50 个名额，余数给权重小数部分更大的层。抽出的人数和这个配额一致。年龄和性别不是这一次的分层变量，它们是层内加权抽样带出来的。

模型真正分开的三题

逐人逐题对照，gpt-5.5 与 glm-5.3 有 622/700 题相同（88.9%），与 deepseek-v4-pro 有 609/700 题相同（87.0%）。分歧最多的是宗教活动：gpt-5.5 和 deepseek-v4-pro 在 50 人里有 34 人答案不同。

宗教活动：deepseek-v4-pro 把「很少」换成了「从不」

Twin-2K 里「从不」占 40.7%，「很少」占 22.5%。gpt-5.5 有 66% 的人答「很少」、12% 答「从不」。glm-5.3 是 60% 和 20%。deepseek-v4-pro 是 22% 和 60%，TVD 从 0.435 降到 0.231，份额 MSE 从 0.0466 降到 0.0094。两种指标在这一题上给出同一个第一名。

党派：只有 gpt-5.5 留出了独立选民

Twin-2K 是共和党 26.2%、民主党 41.2%、独立 29.6%。gpt-5.5 给出 22%、50%、28%，TVD 0.088、份额 MSE 0.0027。glm-5.3 和 deepseek-v4-pro 把独立选民压到 8% 和 10%，共和党升到 42% 和 38%，份额 MSE 是 0.0200 和 0.0162。三个模型都没有人答「其他」。

政治倾向：glm-5.3 分散在保守和温和之间

Twin-2K 从非常保守到非常自由派大约是 7%、21%、28%、27%、17%。gpt-5.5 有 70% 答温和，自由派只有 6%，两端为 0。deepseek-v4-pro 有 58% 温和、6% 自由派。glm-5.3 是 48% 温和、36% 保守、16% 自由派，TVD 0.348、份额 MSE 0.0215。gpt-5.5 的份额 MSE 是 0.0507，因为 70% 对 28% 的温和档被平方放大。

三个模型一起偏掉的分布
